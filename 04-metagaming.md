# 4 · Metagaming

**4.1.** Metagaming é o uso de informações obtidas fora do personagem (Discord, stream, chat OOC, conversas externas) para tomar decisões dentro do roleplay. É estritamente proibido.

**4.2.** Informações vistas em streams ou lives de outros jogadores não podem ser utilizadas pelo seu personagem, mesmo que você "coincidentemente" estivesse no local.

**4.3.** Reconhecer um jogador pela voz, nome de usuário ou informações de outra sessão de jogo para agir dentro do roleplay é considerado metagaming.

**4.4.** Repassar localização, planos ou informações estratégicas de um personagem para outro jogador fora do roleplay é proibido.
